# 🤝 RedeExcedente - Plataforma de Trocas Inter-ONGs

> Projeto desenvolvido para o **Projeto Integrador II** do curso de Bacharelado em Tecnologia da Informação / Engenharia de Computação / Ciência de Dados da **UNIVESP (Universidade Virtual do Estado de São Paulo)**.

---

## 📌 Sobre o Projeto

O **RedeExcedente** é uma aplicação web desenvolvida para mitigar o desperdício de recursos e fortalecer a cooperação interinstitucional no terceiro setor.

Muitas Organizações Não Governamentais (ONGs) recebem doações em excesso de determinados insumos (como alimentos, móveis, equipamentos de TI e materiais escolares) enquanto outras enfrentam escassez dos mesmos itens. A plataforma atua como um elo logístico e comunitário, permitindo que as instituições publiquem seus excedentes e encontrem recursos disponíveis filtrados por **categoria** e **zona geográfica de atuação**.

---

## 🚀 Funcionalidades Principais

- **Mural de Excedentes:** Listagem dinâmica dos itens disponíveis para doação/troca com filtros por categoria e região.
- **Cadastro de Materiais:** Formulário para publicação de novos itens com controle de quantidade, estado de conservação e prazos.
- **Identificação Institucional:** Registro simplificado de ONGs para validação e transparência das trocas.
- **Contato Direto:** Integração rápida via WhatsApp/telefone para agilizar a logística e a retirada dos insumos.

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** React, TypeScript, Tailwind CSS, Lucide React
- **Build Tool:** Vite
